# Política de Privacidade — ClipBear MVP

> Preservada do projeto original. Ver também [09-dados-persistencia.md](09-dados-persistencia.md).

## O Que Coletamos

**Apenas Padrões de Uso de Apps:**
- Quais aplicativos estão em primeiro plano
- Quando você liga/desliga a tela
- Tempo gasto em diferentes aplicativos
- Informações básicas do dispositivo (versão do SO, versão do app)

**O Que NUNCA Coletamos:**
- Mensagens pessoais ou conteúdo
- Fotos, vídeos ou arquivos
- Dados de localização
- Informações de contato
- Histórico de navegação
- Identificadores pessoais

## Armazenamento

- **Apenas Local**: Todos os dados no dispositivo
- **Criptografado**: Chaves específicas do dispositivo (Hive encrypted)
- **Sem Nuvem**: Nunca enviados para servidores
- **Deletável**: Apagar tudo a qualquer momento

## Seus Direitos (LGPD/GDPR)

- **Acesso**: Visualizar dados no app
- **Exportar**: Download em JSON
- **Deletar**: Remoção permanente
- **Controlar**: Desabilitar coleta a qualquer momento

## Rede

Builds de release não fazem chamadas de rede. Integrações externas exigem opt-in explícito.
